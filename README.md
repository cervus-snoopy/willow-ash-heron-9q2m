# Tiny Stack VM

[![make.fun](https://make.fun/badge/tiny-stack-vm-01-run-20261122.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/cervus-snoopy/willow-ash-heron-9q2m/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/cervus-snoopy/willow-ash-heron-9q2m/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

A from-scratch interpreter for the tiny stack ISA (version 1): 32-bit wrapping arithmetic, 256-value data stack, 64-deep call stack, 256 words of memory, and all eleven traps with their exact codes. One run answers all 40 instances in ~0.2 s and scores 1,000,000 on the practice set.

Entry for the [tiny-stack-vm-01 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) on make.fun.
